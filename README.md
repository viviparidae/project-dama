# プロジェクトダマ (Project Dama)

> **"Tame the modern stimuli, honor your biology."**  
> 現代の過剰刺激から脳と身体を守り、本来の生命力と自己コントロール力を取り戻すヘルスケア＆習慣化アプリ

---

## 📌 プロジェクト概要 (Overview)

**プロジェクトダマ（Dama）**は、現代社会における**進化的ミスマッチ（Evolutionary Mismatch）**を軽減・解消することを目的としたプロダクトです。

サンスクリット語で「感覚の制御・自己コントロール」を意味する **Dama（ダマ）** の名の通り、飽食・人工光・座りっぱなし・SNSの通知バーストといった現代特有の過剰刺激に対し、人間が本来持っている生物学的メカニズムに沿ったアプローチで自己統制をサポートします。

---

## 🧬 進化的ミスマッチ（Evolutionary Mismatch）とは？

人類の遺伝的特性や身体メカニズムは、何万年もの狩猟採集時代（EEA: 進化適応環境）において最適化されてきました。しかし、近年の急速なテクノロジーや環境の変化に生物学的な進化が追いつかず、現代の環境と身体の間に「ズレ（ミスマッチ）」が生じています。

* **食行動のミスマッチ:** 超加工食品や精製糖に対する脳の報酬系（ドーパミン）の過剰反応・生活習慣病
* **光と睡眠のミスマッチ:** 夜間の強烈なブルーライトによるメラトニン抑制と体内時計の乱れ
* **身体運動のミスマッチ:** 長時間の座りっぱなしによる代謝・循環の低迷
* **認知・注意力のミスマッチ:** SNSや際限のない情報による過剰な他者比較とメンタル負荷

## 🚀 主な機能 (Key Features)

1. **食行動コントロール（満腹ラグタイマー / 超加工度チェック）**
   * 満腹信号が脳に届くまでの約20分間をペーシングする食事タイマー
   * 脳がバグりやすい高カロリー・超加工食品の可視化とアドバイス

2. **サーカディアンリズムの最適化（日光・光暴露トラッカー）**
   * 朝の太陽光浴び不足や、夜間の過剰な人工光露出を可視化
   * 日没に合わせた「デジタル日没モード」による睡眠環境のサポート

3. **身体活動の促進（マイクロムーブ・NEATトラッカー）**
   * 30分ごとの軽運動（ストレッチやスクワット）のリマインド
   * 座りっぱなし（静止ブロック）の時間可視化

4. **デジタルデトックス・認知保護**
   * ダンバー数（150人）や親しい関係性に焦点を当てたコミュニケーション設計
   * 報酬系刺激をカットするためのバッチ通知・フィード遅延機能

## 💻 開発の進め方 (Getting Started)

### 前提条件 (Prerequisites)

* Node.js 18.x 以上
* npm
* Git

### ローカル環境でのセットアップ (Installation)

リポジトリをクローン済みであれば、プロジェクトルートから次のコマンドを実行します。

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

開発サーバーは次のURLで起動します。

```text
http://localhost:3000
```

### 本番ビルドと起動

```bash
# 本番ビルド
npm run build

# 本番サーバーの起動
npm start
```

### 実行方法の注意

本リポジトリにはNext.jsの`app`または`pages`ディレクトリが存在しないため、現在の状態では`npm run dev`を実行しても、ブラウザー画面を表示できません。フロントエンドのNext.js画面を追加後、上記のコマンドでアプリを起動できます。

### 主なスクリプト

```bash
npm run dev       # 開発サーバーを起動
npm run build     # 本番ビルド
npm start         # 本番サーバーを起動
npm run typecheck # TypeScriptの型検査
npm run test      # テストスイートを実行
```
