## 1. プロダクトビジョン

> **「現代の過剰刺激を飼い慣らし、生物学的本来の姿を取り戻す。」**  
> *"Tame the modern stimuli, honor your biology."*

**プロジェクトダマ（Dama）** は、現代社会における **進化的ミスマッチ（Evolutionary Mismatch）** を軽減・解消するヘルスケア＆習慣化プロダクトである。サンスクリット語で「感覚の制御・自己コントロール」を意味する名の通り、食・光・運動・デジタル刺激の4領域において、ユーザー自身の生物学的メカニズムに沿った自己統制をサポートする。

---

## 2. 背景と問題定義

人類の身体メカニズムは数万年の狩猟採集時代（EEA: 進化適応環境）に最適化されてきたが、近年の急速なテクノロジー・環境変化に生物学的進化が追いつかず、4つの領域で「ズレ（ミスマッチ）」が生じている。

| # | ミスマッチ領域 | 問題の本質 |
|---|---|---|
| 1 | **食行動** | 超加工食品・精製糖に対するドーパミン報酬系の過剰反応、満腹シグナルの20分遅延 |
| 2 | **光と睡眠** | 夜間ブルーライトによるメラトニン抑制・体内時計の乱れ |
| 3 | **身体運動** | 長時間座位による代謝・循環の低迷、NEAT（非運動性熱産生）の低下 |
| 4 | **認知・注意力** | SNS通知・無限スクロールによる過剰な他者比較とメンタル負荷 |

---

## 3. ターゲットユーザー（ペルソナ）

### プライマリペルソナ：バイオハッカー型ユーザー
- **年齢層**: 10代〜30代
- **特徴**: 健康意識が高く、自己最適化・パフォーマンス向上に積極的
- **ニーズ**: 科学的根拠に基づいた習慣化ツールで、現代環境のノイズをコントロールしたい
- **課題**: 意志力だけでは対抗困難な設計（無限スクロール、超加工食品など）に毎日さらされている
- **文脈**: スマートフォンを常時携帯、Webブラウザも日常的に使用

## 4. プロダクトスコープ（MVP）

### 4.1 スコープ内（In Scope）

MVP ではWebアプリケーション（Next.js）として以下の4機能領域を提供する。

#### 機能領域 1：食行動コントロール
- 満腹シグナルが脳に届くまでの **約20分間をペーシングする食事タイマー**
- 摂取した食品の **超加工度を可視化**し、ドーパミン報酬系の過剰反応リスクを通知

#### 機能領域 2：サーカディアンリズム最適化
- 朝の **日光浴び記録**と、夜間の **人工光暴露量の可視化**
- 日没時刻に連動した **「デジタル日没モード」** によるスクリーン輝度・カラー調整促進

#### 機能領域 3：身体活動促進
- **30分ごとのマイクロムーブ（軽運動）リマインド** による座位ブロックの分断
- 静止継続時間の可視化（NEAT トラッキング）

#### 機能領域 4：デジタルデトックス・認知保護
- **バッチ通知モード**：SNS通知を即時配信せず、設定した時間帯にまとめて受け取る
- **フィード遅延機能**：外部サービス情報の意図的な遅延表示によりドーパミン刺激を低減

### 4.2 スコープ外（Out of Scope）

以下はMVP対象外とし、将来フェーズで検討する。

- モバイルアプリ（Flutter / React Native）への対応
- ウェアラブルデバイス（Apple Watch / Garmin 等）との連携
- AI によるパーソナライズドコーチング・推薦エンジン
- ソーシャル機能（友人との比較・共有）
- 有料サブスクリプション・課金機能

## 5. 技術スタック（MVP）

| 層 | 採用技術 | 根拠 |
|---|---|---|
| **フロントエンド** | Next.js（Web） | SSR・SSG対応。将来のFlutter移行を見据えAPIファーストで設計 |
| **バックエンド** | Supabase（認証 + PostgreSQL + REST/Realtime） | サーバーレス運用、Row Level Security でユーザーデータを保護 |
| **アーキテクチャ** | Clean Architecture | ドメインロジックをフレームワーク非依存に保ち、Flutter移行コストを最小化 |

## 6. 成功指標（MVP）

| 指標 | 目標値 | 測定方法 |
|---|---|---|
| 食事タイマー完走率 | 初回利用から7日間で60%以上 | Supabase イベントログ |
| マイクロムーブ応答率 | リマインド通知への反応率40%以上 | 通知→アクション完了のファネル |
| デジタル日没モード有効化率 | 登録ユーザーの50%以上が設定 | ユーザー設定レコード |
| 継続利用率（Day 7） | 40%以上 | コホート分析 |

---

## 7. 制約条件・前提

- **データプライバシー**: 健康データはユーザー本人のみ参照可能（Supabase Row Level Security 必須）
- **オフライン対応**: MVP ではオフライン動作は保証しない（ネットワーク必須）
- **ブラウザ対応**: Chrome / Safari / Edge 最新版（モバイルブラウザ含む）
- **表示言語**: MVP は日本語のみ。ブラウザの優先言語が日本語の場合、ユーザー向け表示を日本語で提供する（NFR-I18N-01）
